# Changelog

## 0.1.1

- Python: SQL on the line after `r"""` or `r'''` (lowercase `r`) is now
  highlighted. Raw strings that aren't SQL keep VS Code's regex highlighting.

## 0.1.0

- First release. SQL highlighting in JavaScript, TypeScript, JSX and TSX (`` sql`...` `` and
  strings or template literals starting with an SQL keyword), Python, Go, Java
  and C# strings.
